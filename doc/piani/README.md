# Piani

Qui sta ogni lavoro con un numero di milestone (`M<nn>`) o con un task (`HER-12`): cosa faremo e cosa abbiamo fatto.

- Ogni piano è una cartella: `M<nn>-<nome>/` oppure `<TASK>-<n>-<nome>/`, per esempio `M12-ricerca-veloce/`.
- Dentro ci va `PIANO.md`, con le due parti «In una pagina» e «Per chi esegue». Se serve: `FASE-<n>.md` per le fasi e `DOMANDE.md` per le domande aperte.
- Un piano finito resta qui con lo stato `eseguito`. Quando non serve più, si sposta in `doc/archivio/`.
- Un lavoro senza numero non è un piano: è un'idea, e va in `doc/idee/`.

Le regole complete sono nello standard della documentazione (`STANDARD.md` del plugin `documentazione`).
