# Funzioni del launcher

Cosa potrebbe fare la Home vera, dopo il launcher minimo di M01. Da trasformare nel piano M02 dopo l'analisi delle funzioni.

## Prima proposta di Home

```
┌────────────────────────────────────┐
│  16:42                    🌡 9°C   │
├──────────────────┬─────────────────┤
│                  │                 │
│   NAVIGATORE     │   IN ASCOLTO    │
│   (tocca e apri) │   copertina     │
│                  │   ⏮  ⏯  ⏭      │
├──────────────────┴─────────────────┤
│  [app] [app] [app] [app]  [⋯ tutte]│
└────────────────────────────────────┘
```

## Funzioni candidate

| Funzione | Come si farebbe | Nota |
|---|---|---|
| Navigatore in un tocco | Apre Waze o Google Maps | |
| Scheda «in ascolto» | Legge brano e copertina dalle sessioni media, con i comandi | Serve una volta il permesso «accesso alle notifiche» |
| Scorciatoie | 4–6 app scelte, più la griglia di tutte le app | |
| Azioni all'accensione | Aprire il navigatore, far ripartire la musica | |
| Temperatura esterna | Da un servizio meteo via internet | Il box non legge i sensori dell'auto |
| Velocità o posizione | Dal GPS | Solo se il box ha un GPS suo |

## Domande per l'utente

1. Quali app usi in macchina: navigatore, musica, altro?
2. Di Car Launcher cosa usi davvero e cosa ti dà fastidio?
3. Vuoi azioni automatiche all'accensione?
4. La temperatura da internet ti interessa?
