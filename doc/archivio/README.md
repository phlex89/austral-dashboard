# Archivio

Qui stanno i documenti che non descrivono più il presente: lavori chiusi, analisi vecchie, piani superati.

- Un file si sposta qui con `git mv`, senza modificare il testo. Si correggono solo i link relativi.
- Più documenti dello stesso lavoro vanno in una sottocartella, per esempio `M12-ricerca-veloce/`.
- Qui non valgono regole di formato, e di solito non si legge: si cerca solo per capire il perché di una scelta passata.

Le regole complete sono nello standard della documentazione (`STANDARD.md` del plugin `documentazione`).
