# Idee

Qui stanno le idee senza un numero di milestone né un task: bozze, proposte, cose da decidere.

- Ogni idea è un file: `<nome>.md`, in minuscolo e con i trattini, per esempio `ricerca-veloce.md`.
- Il file comincia con `stato`, `data` e `lettori`, poi un titolo e due righe su cosa si vorrebbe e perché.
- Quando l'idea diventa un lavoro vero, nasce un piano in `doc/piani/` e l'idea si sposta in `doc/archivio/`.

Le regole complete sono nello standard della documentazione (`STANDARD.md` del plugin `documentazione`).
